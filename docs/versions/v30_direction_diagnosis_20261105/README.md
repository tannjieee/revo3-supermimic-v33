## 已确认的现象

### 1. 更新方向主要来自 bootstrap，不是短程姿态奖励

使用现有 seed=43 独立评估回放，三个固定抽样种子 41/42/43，每批 128 条历史。
完整复现原 8 步 AR(1) 探索、反射、观测噪声、终止、正则和目标 Critic；
分解后的总目标必须与生产 `imagine_stable` 一致（误差 <2e-6，实际值见 JSON）。
不更新网络、统计量或优化器。这里的范数是裁剪/Adam 之前的参数梯度。

| 项目 | 三批结果 |
|---|---|
| 短程奖励梯度范数 | 0.0101 / 0.0165 / 0.0292 |
| 奖励 bootstrap 梯度范数 | 1.141 / 1.179 / 1.358 |
| bootstrap / 短程奖励范数 | 113 / 72 / 46 |
| 加权代价 / 总奖励范数 | 1.66 / 1.39 / 1.41 |
| 加权代价在总梯度上的投影比例 | 63.6% / 58.7% / 59.6% |

五个代价 bootstrap 头的范数几乎相同，每头约 0.33–0.39；真正的即时速度/目标速率代价
梯度仅约 0.0008–0.0024。共同失败风险在每个代价头都存在，这是现有定义的明确结果，
不是本轮新增的惩罚。不能据此断言所有五头都冗余，但应优先检验共同风险的重复权重。

另将末端 Critic 的输入梯度拆成物理状态路径与 last_action 直达路径：固定存活权重后，
last_action 直达路径占 bootstrap 总梯度投影约 22%–30%，物理路径占约 70%–78%；
两者加和相对误差约 1e-7。动作历史是合法的动力学信息，不能因为存在直达梯度就删掉输入，
但这条路径可让 Actor 在未改善物体姿态时改变估值，需要真实分支回报校验。

### 2. 小 TD 残差不能验证长期价值或其导数

冻结确定性真实回放上，严格排除 reset 后转移，真实失败截断、超时从 pre-reset 状态自举。
8 步奖励标签仍约 90.1% 来自 bootstrap；128 步降至 27.6%。
奖励头归一化 MAE 从 8 步的 0.00307 增为 128 步的 0.0230；风险头约从 0.0096 增为 0.0475。
128 步奖励估值均值 2.01、真实前缀+尾值标签均值 2.38；风险头约 7.56 对 5.38。

这不是无 bootstrap 的 MC 真值，窗口起点数也不同，不能将差异归因于单一因素。
评估策略关闭探索，与训练随机行为不同；原训练 Replay 未随检查点保存，
因此本轮**没有测出离策略偏差的因果大小**。目前证据支持加强价值校验，
不支持声称改成 1 步/32 步一定解决问题。

### 3. 目标使用弱，当前数据覆盖确实偏静止

沿用已验证的目标交换诊断：固定历史一致地替换目标，绝对角变化均值仅 0.221°。
本轮新测目标输入标准差 0.55–0.60，无目标通道低方差异常放大的证据。
确定性评估中单步物体旋转增量中位数 0.0403°、P90=0.287°；
距离目标 <30° 的状态仅 1.53%，<10° 为 0。上述是评估分布，不是训练探索分布。

seed=43 中连续存活 10 秒的 41 个环境，配对姿态误差改善均值 -4.79°，
12 个改善 >10°、20 个恶化 >10°。有存活者选择偏差，但没有把 reset 分布变化当成进展。
这支持增加有转动响应的辨识数据/目标覆盖；还不能证明 0.5° 探索本身是唯一瓶颈。

## 局部动作响应：方法与适用范围

独立进程同 seed、同动作前缀重放失败：初始观测状态与 context 相同，
但扰动前物理轨迹已不同；检查器拒绝此数据，不报告虚假的 Jacobian。
原始基线/重放/正负分支文件保留在外部根目录。

随后采用同一运行内分支：保存并原位恢复 Adapter/环境、执行器迟延、缓存、
Newton backend、solver/contact/pipeline 的 Torch/Warp 缓冲及 Python/NumPy/Torch RNG。
保存规模 190 个 Torch 张量、1009 个 Warp 数组、995 个对象（首组实测）。
此机制只是诊断快照，**不是通用训练 checkpoint 或严格确定性恢复承诺**。
所有分支仍执行原始 Adapter.step，机械健康、容量和奖励一致性检查不变。

每个环境扰动一个关节（env_id % 21），初始命令加/减物理角，之后保持同一个绝对命令 7 步；
这是开环辨识输入，不是策略滤波、积分器或新的输出协议。距限位不足的环境排除，不能 clamp 后当对称差分。
保留域参数与感知随机化；不修改 solver 配置或引擎代码。

每个起点运行四个零扰动分支、两次正扰动与两次负扰动，后两次逆序执行。
全部物理起点须逐位相同。求解仍有残余非确定性，因此逐环境/时距取零扰动和同号重复
姿态差的最大值作为经验噪声；仅分析响应范数 >10×max(噪声,1e-6 rad) 的样本，
并排除终止后的样本。它是有限幅度响应检验，不是全部 21 列的无穷小 Jacobian，
噪声界仅来自有限重复，不是统计置信保证。可解析样本选择偏向有接触响应的方向。

首组：seed=44、控制步 128、±0.5°，64 环境，58 个具备对称限位余量。
单步可解析 13 个响应，方向余弦均值 0.162、向量相对误差 0.926；
8 步可解析 13 个响应，方向余弦均值 0.039、相对误差 1.164。
单步基础姿态预测误差仅约 0.525°，并不能保证约 0.02° 量级的动作响应方向可信。
独立复核 seed=45、控制步 256、±1°：单步 16 个可解析响应，方向余弦 0.201、相对误差 0.994；
8 步 13 个响应，方向余弦 0.115、相对误差 1.736。对奖励变化再施加同样的重复噪声筛选，8 步方向一致率分别为 5/12、5/11。
这加强了局部响应不可靠的证据，但仍不能外推全部状态/关节或 1024 个域参数。
全部时距与样本数量见 `response_seed44.json`、`response_seed45.json`。

## 按证据与预期收益排序的下一轮优化

1. **优先修复/验证 WM 的动作响应学习。** 在保持原物理随机化与健康保护下，
   收集成对小幅度绝对命令扰动，以动作引起的旋转差增加局部响应监督；保留全部现有状态、
   奖励、观测、代价及终止损失。用独立状态/域参数/关节方向验证，不能拿拟合过的分支证明泛化。
   先做 WM-only 对照；通过后再小规模 Actor 更新。当前两次有限扰动仅能作为问题证据，
   不足以直接训练或设置全局梯度门槛。导数可靠性门槛应先于长训练。
2. **限制未经验证的 bootstrap 对策略方向的主导。** 做固定真实历史上的短程奖励、
   完整 bootstrap、停止 bootstrap 输入梯度三组诊断，再以真实分支奖励进展/掉落/速度验证方向。
   同时检验“单独失败风险 + 各类运行风险”的目标定义，避免共同掉落惩罚重复计权。
   这会改变 Critic 标签/上界/目标语义，需要新版本新训练，不能静默 resume 旧六头。
   不直接删掉所有生存惩罚，也不以只剩弱短程奖励作为已验证方案。
3. **提高有用探索与目标覆盖。** 比较当前逐关节 0.5° 相关探索与少量协调绝对角扰动，
   记录接触中的真实转角、目标方向进展、掉落和两类速度违规；不加入目标速率过滤。
   可另测目标重标记/由近及远目标采样，但历史相对姿态、奖励、接近目标时物体速度代价都必须一致重算；
   目标采样变化须显式版本化，最终仍评估原目标分布，不能只报容易目标成功率。
4. **再处理 Critic 的回放时效性/离策略偏差。** 记录采集策略版本、行为噪声与当前动作差，
   对比近期真实窗口和现有均匀窗口；先用冻结策略真实回报校验，再决定步长或校正方法。
   不能套用忽略 AR(1) 隐状态及反射概率密度的朴素重要性比。

不优先：继续压低速度阈值、单纯延长想象轨迹、只改 tanh/输出协议、直接长训。
其中延长不可靠 WM 的 rollout 可能放大梯度错误；本轮没有证明任何新训练方案收敛。
