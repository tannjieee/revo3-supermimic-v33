# S1目标速率120°/s对照

用户同意将关节目标速度从60°/s提高至120°/s，仍是25Hz绝对位置目标，因此每步可达区间由±2.4°增至±4.8°。configs/flashsac_die47/task_rate120.json与原task.json唯一配置差异为cost_target_rate_limit_rad_s；采集、Actor、TD、目标速率成本及发送前保护共同使用新参数。其他阈值不变：实际关节速度风险仍90°/s，物体角速度仍0.5rad/s，物体线速度仍0.05m/s。

动作协议明确标记为120deg_s，检查点版本flashsac_revo3_die47_hist25_s1_rate120_v1，禁止用60°/s Agent直接加载覆盖映射buffer。初始物理探索尺度仍0.5°，故局部pre-tanh初始std按同一公式从0.20833变为0.10417；这是固定物理噪声初始化的结果，不宣称所有初始网络张量完全一致。目标熵仍定义在局部坐标，增大区间也扩大同一局部熵对应的物理探索范围，这是本次动作合同变化的含义。

9项语义测试通过，包括4.8°边界、4.7°接受/4.9°拒绝、初始HOME、版本隔离及原官方更新等价测试。未修改官方算法/引擎源码，不改变随机化、奖励系数、网络、n-step或噪声重复（仍每步重采样）。
