## 3. WM：状态预测与动作效果必须分别验证

### 3.1 方法和样本限制

同一进程恢复物理、传感器、延迟缓冲、历史及 RNG，在第一步向单个关节施加 ±1° 命令扰动，后 7 步使用同一基准命令序列。每个起点包含 4 个零扰动、2 个正扰动、2 个负扰动分支。以零分支和同号重复分支的最大差异估计经验噪声，只把超过噪声 10 倍及绝对小量门槛的效果计为“可辨”。精确恢复初态不代表接触求解轨迹逐位重复。

512 起点中 403 个具有对称扰动限位余量，8 步全部分支存活的有 400 个。重复时刻共享同一域环境，置信区间按环境聚类；这不是 512 个完全独立实验，也不是完整 21×物理状态 Jacobian。±1° 是有限幅度差分，不等于无穷小导数。

| 1 步关节 q | 384 | .8744 | .4806 | .6340 |

## 4. bootstrap 主导复现，但不能由比例推导方向错误

冻结模型，在独立 seed43 评估中抽取三批各 128 个真实状态/历史，保留训练想象目标、探索变换、感知模型及全部梯度链路。无优化器或统计更新。重新拼出的目标与生产 `imagine_stable` 最大误差约 1.2e-8。

| 检查点 | 奖励尾值 / 8 步奖励的 Actor 参数梯度范数 | 加权代价 / 全部奖励的 Actor 参数梯度范数 |
|---|---|---|
| 500 | 34.36、13.05、10.63 | .0177、.0181、.0157 |
| 1500 | **72.16、308.03、87.57** | **1.64、.79、3.31** |

这是抽样梯度范数比，不是 Adam 更新比例，三批也不是三个独立训练。它确认当前策略对尾值非常敏感，不能单独证明尾值方向错误。原来的“代价高于奖励 8–53 倍”不是本轮数据。

H=8 在 25 Hz 下仅覆盖 .32 秒；γ⁸=.922745。在恒定回报的质量分解中，短程占 7.73%，尾部占 92.27%；有效折扣时长约 4 秒，95% 折扣质量约需 12 秒。**这不是梯度占比公式**，但说明 H/γ 的组合本来就要求 Critic 提供很大部分的长期判断。合法系统也可能有很大的尾值/短程梯度比，不能机械地把它调成 1。

切断尾端 last_action 直接输入和物理状态路径分别做冻结分解：model1500 的尾值投影主要经物理状态路径，FP32 三批约 104.1%/86.0%/94.2%；超过100%表示另一条路径反向抵消，不是概率。model500 则相反，last_action 直接投影约 53.8%–65.7%。因此两阶段不能混说，也不能只靠删除 Critic 的 last_action 解决最终问题。该分解单独固定存活权重，主梯度实验没有断开它。TF32 关闭后，三批尾值比仍为 72.29、308.14、87.77；加法残差由约 4e-4–6e-4 降至 3e-7–7e-7，说明残差与数值精度有关，**主导关系本身并非 TF32 产物**。

### 4.1 新发现：TD8 与 target EMA 联合作用的慢冷启动

当前每个外层迭代完成 20 次在线 Critic minibatch 更新，再做一次 target EMA。即使假设在线 Critic 每轮完美拟合 TD8，固定策略、近恒定每步奖励 r 下，令 c=r/reward_bound（对应归一化无限回报），仍有：

```text
β = γ^8
U_n = (1−β)c + β Z_(n−1)
Z_n = (1−τ) Z_(n−1) + τ U_n
误差乘数 q = 1−τ(1−γ^8) = .998454894
误差半衰期 ln(.5)/ln(q) ≈ 448.26 轮
```

这里 Z 是 target 值、U 是拟合后的 online 值。**448 轮是 TD 自举与 EMA 共同形成的标量基准，不是仅 EMA 的 34.31 轮半衰期，也不是实测神经网络必然服从的时间常数。** 500 轮后 .01 的零风险先验在理想 target 中仍保留约 .00462，理想 online 为 .00427；实际 online drop 均值 .00454，TD MAE 却只有约 1.3e-5。小 TD 只表示追上移动标签，不保证接近真实长回报。

独立 HOME 检验进一步支持这一机制：model500 的 Actor 从未更新，64 环境从同一真实时刻取 256 步无失败/超时前缀。

| 同一实际起点，归一化奖励 | 数值 |
|---|---:|
| target Critic 值均值 | .034974 |
| online Critic 值均值 | .037165 |
| 真实 256 步正奖励前缀均值，不加任何 Critic | **.059243** |
| 两个 Critic 各自低于真实前缀的状态 | **42 / 64** |
| 未拟合参数的冷启动标量预测对实际 target 输出的 R² | .904 |

每步回报在这些窗口内近恒定，range/mean 的 P90 为 .73%；解析模型因此有实际适用依据。不过训练保留 AR 探索、独立评估关闭探索，不能把全部低估都归因 EMA。**值偏小也不等于方向错误**；正比例缩小仍可能保留方向。证据见 `E/bootstrap/cold_start.md` 和 `home_value_calibration.json`。

### 4.2 长闭环验证没有得到足够的长期方向真值

新增 10.24 秒真实闭环：仅第一步 ±1°，之后每步由冻结 Actor 根据各分支的真实历史重新出动作。每起点四零、两正、两负；初始状态/历史一致，模型 hash、normalizer、优化器计数保持。两个起点分别有 41/55 个对称限位合法环境。

128/256 步奖励差分没有样本通过重复噪声筛选；在实际第 8 步状态上读取 Critic 并与后续真实 suffix 对照，同样没有可辨的长期差分。零扰动分支本身在长时域就产生不同失败时序。因此不能报“长期方向准确率为 0%”，也不能用同一个 Critic 补进真实标签来制造验证通过。

256 步后仍有 γ²⁵⁶=.076315 的折扣尾质量，有限前缀不是无限时域真值。唯一能由完整 episode 边界确定方向的反例，其所有分支恰在第 8 步失败；那仍是短末端样本，不代表一般长期价值。将“8 步奖励+Critic”拿去与纯 8 步真实前缀比较，也有时域不匹配，不能据此裁决 Critic 长期方向。

这次检查真正留下的结论是：**Actor 严重依赖尚未获得独立长期导数验证的 Critic；短程 WM 错误已得到独立证据。** 完整长分支结果及未通过筛选的样本仍保留：`E/bootstrap/current_v31/tail_findings.md`、`tail_analysis.json`。

## 5. 代价不是单纯“权重不够”：映射形状也有问题

关节速度/目标变化先取 21 关节中最大阈值比 x，再计算：

```text
c = max(x−1, 0)^2
risk = c/(1+c)
drisk/dx = 2(x−1) / [1+(x−1)^2]^2       (x>1)
```

导数最大约 .6495，x≈1.577；严重超限后按约 x⁻³ 下降。最终实际评估中：

| 指标 | joint_speed | target_rate |
|---|---:|---:|
| 最大阈值比中位数 | 8.252 | 9.366 |
| bounded risk 中位数 | .98134 | .98591 |
| 违规样本 drisk/dx 中位数 / 峰值 | **.763%** | **.501%** |
| 全部样本中违规且导数<峰值1%的比例 | 53.07% | 58.83% |
| 每条转移超限关节数中位数 | 8 | 11 |

`amax` 在这些样本中均为唯一最大值，因此该时刻该项的直接梯度只选择一个关节；其余时间、其他风险、模型和尾值路径仍可提供梯度。不能把上表解释成“整个 Actor 梯度被压低 200 倍”。但这已经表明：**有界风险有利于值域稳定，却会弱化严重超速后的直接纠正，并对非最坏关节缺少稠密信号。** 单纯增大 .05 的权重不能修复这种形状。

新1500模型也不能继续解释成“五头只是共同失败风险”。joint_speed/target_rate 减去 drop 后的输入导数残差达到本头范数 46.5%/62.6%；它们相对 drop 已存在显著非共同导数分量，但这不等于独有运行价值已校准正确。两个物体速度头与 drop 仍高度重合（余弦约 .99993/.99999）。每头都包含同一吸收失败项，按五个 .05 相加，共同失败权重仍为 .25。后续若拆成独立失败头，先保持这个总权重才能隔离“表达方式变化”与“目标变化”。

## 6. 哪些原因优先，哪些仍只是候选

### 6.1 最有依据的机制链

1. **固定 HOME 周围的数据未充分辨识控制响应。** 预训练末期物体增量旋转 std 仅 .00037–.00071 rad，低于 .005 rad 的 loss floor；小总 loss 不代表学会接触旋转。实测 .5° 探索并未被缩放消掉，但只产生有限物体激励。单步脉冲多数方向真实效果太小，后续需更可辨的数据。
2. **按轮数开始 Actor，未要求响应或 Critic 导数达标。** 早期 501–751 轮在线 cost/reward 梯度仅 .02–.056，不能用旧的代价压制解释最初动作扩张。Critic 仍在冷启动收敛；奖励 bootstrap 数值上涨部分可在完全不动的策略上发生，不能全部叫作模型利用。
3. **动作分布扩张后，错误的多步动态和尾值可能形成反馈。** 首次速度违规 773、目标变化违规 775、掉落 791；WM loss 与动作变化在此之前/附近上升。后期真实 q/qd 脉冲尾部和物体响应都不可靠。时序支持该机制，但尚未证明最早触发来自哪条梯度。
4. **进入大违规区后，运行代价饱和且 Critic 风险追赶。** 后期 joint/target 的真实违规已普遍；再整体压低全部 cost 可能放任更严重运动，不是合理的通用答案。

当前 model1500 的物体旋转/角速度标准差已超过 floor，因此低方差 floor 主要是初期问题，不能用它解释全部最终错误。总 WM loss 的单位和分母随统计变化，不能把 .0017→.405 简化为同一物理误差增长 240 倍。

### 6.2 网络结构与算法假设

当前 WM 是三层 2048 MLP，动力学约 885 万参数；已有明确的一步执行器方向信息。容量不足并非首要已证实原因。一个无接触结构约束的 MLP，可能把平均状态拟合得很好，却拟合错局部控制敏感性。可考虑关节/物体分组输出、显式执行器状态或几何特征，但必须在同数据、同预算下对照，不能从本轮结果直接推出“必须换 Transformer/RNN”。

另一个有依据但尚未量化的候选是 **Critic 状态聚合与行为不一致**：Actor 依赖 10 帧历史和感知状态，Critic 只看当前物理状态、last_action、目标、delay_ready、域参数，未包含完整历史/传感器/AR记忆；真实 TD8 又来自旧行为的均匀 Replay，无当前策略重要性校正。当前 Replay 最多约 40 秒、约 400 外层迭代的数据。当前状态的特权信息不自动保证能确定带记忆策略的未来动作，偏差大小仍需配对/在策略对照，不能靠接口维度推定。

原 [SuperMimic 论文](https://arxiv.org/pdf/2610.28480) 使用同样的三层 2048 WM，但默认想象 H32、50 Hz，并用当前策略想象轨迹的 GAE 训练 Critic；其 H8 消融未达到所选目标回报。这里换成随机物体旋转、H8/25 Hz、真实 TD8 和 target EMA，已不是相同训练算法。原文的成功不能直接证明当前组合合适；也不能据此直接把不可靠 WM 延长到 H32。

[MAAC](https://arxiv.org/abs/2005.08068) 的分析明确涉及模型及价值梯度误差；[VaGraM](https://arxiv.org/html/2204.01464v2) 讨论状态拟合目标与策略优化的目标不一致。它们支持检查控制相关误差的必要性，不构成照搬某个损失就能解决本任务的证据。

### 6.3 不应误诊的参数

- **物体线速度 ×2** 是输入预缩放，后面还有 RunningNorm，并非真实速度乘二。大部分被标准化抵消；当 floor 主导时，相当于物理标准差下限 .005 m/s，角速度对应 .1 rad/s。需检查物理单位下分母和数据覆盖，单删 ×2 通常只是重参数化，不能修复 WM 因果响应。
- **λ** 在当前 stable v31 实际更新中不生效：虽然计算了 imagined lambda targets，Critic 使用真实 TD8，Actor 使用 H 步加尾值。调 λ 不是当前问题的有效实验。
- **学习率** 变小可能减慢扩张，但不能使错误方向变正确；已有 .25 倍 Actor LR 和 ramp，不能当作充分保障。
- **H/γ/τ** 必须联合看：减小 γ 改任务时域，删除尾值丢掉长期风险，延长 H 会积累 WM 误差，增大 τ 加快传播也可能放大噪声。需要对照，不能一次全改。
- **目标分布** 当前为两个独立随机角构造 `qx(α) qy(β)`，并非 SO(3) 均匀；固定出生姿态下初始误差<10°约 .176%、<30°约 2.12%。这意味着近目标数据少，不等于目标不可达；更改目标课程也必须作为独立实验，保持固定出生合同。

## 7. 下一步实验顺序与验收标准

本轮没有盲目改默认参数。按以下顺序可以区分“数据、学习目标、结构、更新机制”的责任：

| 顺序 | 冻结什么、比较什么 | 接受证据 |
|---|---|---|
| A：WM 辨识 | 冻结 Actor/Critic；同固定 reset 和随机化下采集多幅度、单步与 .2 s 保持、协调手指方向；普通多步监督 vs 成对响应监督 | 新域/新种子上同时改善方向、幅值、衰减及近静止误报；报告无响应比例，不能靠把预测缩到零获胜 |
| B：Critic | 冻结策略；相同实际起点真实在策略前缀/尾界，比较初始化、TD 长度、EMA 更新安排；历史/行为匹配另设一组 | 同状态真实值校准，且可辨动作差分方向改善；小 TD、低拟合误差均不足；提高分支信噪比后再报长期方向 |
| C：运行代价和 Actor 更新 | 比较高违规区仍有纠正信号的代价、稠密关节聚合及受控参数更新；若拆失败头先保持 .25 语义 | 原 60°/s、90°/s 阈值下真实违规下降，姿态进展不消失，首次命令不再大跳；不改机械限位或偷偷加执行低通 |
| D：结构 | 前述数据/指标固定后，等预算比较现 MLP 与结构化执行器/物体模型、必要的历史表示 | 只有独立真实响应及候选小更新的真实收益优于基线，才判结构变更有效 |

进入下一次 Actor 联合训练前，应加入真实响应和价值校准的准入依据；现有轮数或宽松的前向姿态误差门槛不足以证明可微优化方向可信。数值阈值应先在独立验证集固定，再评价新测试集，不能反复调到已看过的种子通过。
