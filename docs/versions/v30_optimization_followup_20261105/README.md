## ×2 到底改变什么

物体线速度的 ×2 是 WM、Critic 及终止头共享物理特征的输入缩放，不是仿真速度翻倍。
Actor 不直接输入物体线/角速度；速度代价仍按 SI 单位和原阈值计算。

该通道没有额外 std_floor 时，RunningNorm 等价于：

```text
z = (c*v - c*mean_v) / sqrt(c*c*variance_v + eps*eps)
  = (v - mean_v) / sqrt(variance_v + (eps/c)^2)
```

因此固定倍数大部分被方差归一化抵消，真正保留的差别是有效 epsilon，及训练中的数值条件。
当前 c=2、eps=0.01，对应物理 epsilon=0.005 m/s。冻结模型三个轴的有效标准差为
`[0.09720, 0.03137, 0.02424] m/s`，有效输入增益为 `[10.29,31.88,41.25] /(m/s)`。
若将 c 改为 1、同步变换均值/方差但不补偿第一层，实际输入增益变为原来的
`[0.9961,0.9639,0.9417]`，不是简单减半；若仅改 scale 却沿用旧统计，则是错误的分布变换。

额外对第一层列权重作等价重参数化后，模型函数保持一致：WM 输出最大误差约 2.5e-7、
Critic 约 1.5e-5；输入梯度相对范数误差约 2.9e-7 / 1.3e-7，均为 FP32 量级。
这验证了“去掉 ×2 本身”不是修复动力学梯度的手段。该实验没有改写检查点。

仍需优化的是各物理量的有效标准差、分布漂移、损失缩放和可观测性。线速度 y/z 分母小于既有
0.05 m/s 保持阈值，值得做物理尺度下限对照，但阈值不是统计标准差的必然最优值。
不把这一现象当作新增下限已被验证的理由；输入下限、输出增量归一化与物理监督误差下限是三套不同量。

## WM-only 优化对照

### 第一轮：直接加相对响应损失发生过拟合

沿用 seed44 单起点的前48环境训练，seed45 64环境测试。100次 Adam 更新、学习率1e-5，
所有统计冻结，不更新 Actor/Critic。原生产 WM 的8步状态、奖励、干净观测、五项代价和真实终止监督全部保留。
相对响应损失权重0.1，仅使用显著高于重复求解噪声的成对动作响应。

训练8步响应余弦达到0.823，但独立测试仅0.203；同数据上仅继续原监督为0.241。
所以没有将这次训练集改善当作修复或部署候选。

### 第二轮：扩大状态、关节方向与随机域参数覆盖

新增三个64环境评估运行，seed47/48用于训练，seed49作为新的独立测试。
每个运行在控制步64/128/192/256保存真实分支；依次改变扰动关节分配，幅度±1°，仅首步扰动，随后7步保持基准绝对目标。
每起点含4个零扰动分支、2正2负分支，完整恢复内部状态并估计重复求解噪声。
未改随机化、关节范围、物理频率或保护；分支内也执行原健康与容量检查。

训练选择每个64环境快照的前48环境：共384个“状态×环境”起点，来自96个独立随机域环境；
测试256个起点来自64个新域环境。各时刻属于同一环境，不能将这些起点当成全部独立样本。
100次更新、同样学习率1e-5、相同原生产监督；没有调 Actor/Critic 或统计量。

三个预先固定的实验分支：

- ordinary：仅原 WM 监督，学习的数据已包含正负动作分支。
- paired_relative：另加0.1权重逐样本相对旋转响应平方误差，小响应也会得到较大相对权重。
- paired_pooled：另加0.1权重、共享训练集响应尺度的 SmoothL1；尺度取合格训练响应范数中位数、下限1e-4 rad，不使用测试数据选尺度。

| 新 seed49 评估 | 原模型 | ordinary | paired_relative | paired_pooled |
|---|---:|---:|---:|---:|
| 1步方向余弦，79个合格响应 | 0.182 | 0.148 | 0.249 | 0.296 |
| 8步方向余弦，55个合格响应 | 0.040 | 0.056 | 0.222 | 0.123 |
| 8步响应向量相对误差 | 0.990 | 0.986 | 0.991 | 0.984 |
| 原生产监督平均每步损失 | 4.844 | 2.647 | 2.839 | 2.591 |
| 基准8步姿态预测误差均值，全部测试起点 | 5.934° | 3.294° | 3.268° | 3.444° |

结论：扩充成对真实数据明显改善状态拟合，显式响应监督又能提高方向一致性；
但响应幅值相对误差仍接近1，尚未达到可靠策略梯度的水平。relative方案方向提升更大但原监督损失回退；
pooled方案原监督损失与响应误差稍优，但8步姿态误差略高于ordinary。没有一个候选在所有指标上占优。
三者只保存 `*_wm_only.pt`，明确标记 experimental_only，不是可直接 resume 的 Actor/Critic 联合检查点。
测试seed49已用于本轮探索性比较，下一轮调参后需要新数据复核，不能继续把它称为未见测试集。

## bootstrap：不宜仅凭范数直接删除

γ=0.99、H=8 时 γ^H=0.922745，尾值天然有很大权重；“范数大46–113倍”本身并不能证明尾值方向错误。
用前轮真实成对分支比较模型目标对动作的有限差分，尾值权重取0、0.1、1，其他项固定：

| 对照真实8步受约束回报差分 | 尾值0 | 尾值0.1 | 尾值1 |
|---|---:|---:|---:|
| seed44，12个合格响应，方向一致率 | 83.3% | 66.7% | 58.3% |
| seed45，15个合格响应，方向一致率 | 40.0% | 46.7% | 46.7% |

较小尾值并非稳定改善；而真实8步回报也不是无限时域目标真值。将真实分支末端同一个 Critic 加回标签后，
seed45 的方向一致率反而随尾值权重由0到1从27.8%升至72.2%，但那仍含同一个 Critic，不能当作独立证实其准确。
因此本轮没有把0或0.1设置成正式训练默认，也没有仅为降低梯度比例重复调小代价权重。

下一步应使用更长的冻结当前策略真实分支校验奖励/风险尾值，以及其对动作的方向；
同时把共同失败风险重复权重与运行风险分开实验。风险语义变化需要独立新版本和重训 Critic，不能静默沿用旧六头。
改良 WM 后再检验 Actor 的短程/尾值梯度与真实分支的一致性，才有依据逐步恢复联合更新。

## 后续实施顺序

1. 优先扩大接触状态与有用动作方向覆盖，并保留成对响应监督的对照。先改善幅值误差与跨域泛化，不能只追求余弦。
2. 检验已知几何/接触状态特征是否能提高 WM 局部泛化。当前 q/qd/物体位姿/速度包含主要物理状态，但接触映射需要网络学习；求解器内部残余状态也未直接输入。不能据此直接断言状态非 Markov 或强行改引擎。
3. 在独立真实策略分支上验证 Critic 尾值及其方向，再选择 bootstrap 调整；不直接删除生存风险。
4. 单独做物体速度物理标准差下限的学习对照。固定缩放、输入归一化、损失权重分别控制，避免多个开关同时变化而无法归因。
5. 保持现有绝对位置协议及物理阈值；当前没有姿态成功/长程收敛证据，不启动正式长训练。

## 验证与复现

57项测试通过（前53项相关回归+4项新数据完整性检查）：不同物理起点拒绝监督；零扰动重复噪声不能作为响应；响应监督排除终止及reset尾段，原WM监督仍保留终止转移；训练/评估文件重叠会在训练前报错。

脚本：`experiment_v30_response_fit.py`（有限WM-only训练）、`diagnose_v30_scale_bootstrap.py`（缩放/尾值冻结对照）、扩展的`diagnose_v30_snapshot.py`（多个起点和关节方向）。
实验路径与命令见外部日志和同目录`validation.json`；数值结果为`wm_multistate.json`、`wm_single_state.json`与`scale_bootstrap.json`。
