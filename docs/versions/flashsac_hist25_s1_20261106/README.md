## 动作合同

控制周期40ms，目标速率上限60°/s，即每步2.4°。以编码器坐标关节范围[lo,hi]、上次实际发送目标p定义：

- L=max(lo,p−2.4°)，U=min(hi,p+2.4°)。
- Actor输出局部z=tanh(u)，q=(L+U)/2+(U−L)z/2。
- 对PD仍发送绝对编码器位置；Q和replay动作是全范围归一化a=2(q−lo)/(hi−lo)−1。
- reset无上次有效命令时，p使用当前编码器位置（物理关节位置减编码器偏置）。
- 采集、Actor loss和TD next-action使用同一可微映射。没有对采样的全范围动作事后裁剪。
- 熵、温度目标和logπ定义在局部z坐标。这不是全范围a或物理q的概率密度；不添加区间宽度Jacobian，是显式改变的熵正则目标。
- 网络仍只读10×81噪声历史；可靠上一命令/ready/reset编码器只用于控制映射，不输入可学习网络。实现从已存963维观测取这三个控制字段，其余特权字段不进入Actor。
- 初始局部均值0，HOME内对应保持上一目标；接近边界时对应允许区间中点，会略向内移动。初始pre-tanh标准差为0.5°/2.4°，并非边界处精确0.5°物理标准差。
- 保留原有前98步有界HOME激励作为离策略replay预填充，发送前逐步审计；预填充不使用Actor概率或熵。
- 独立发送前保护继续检查有限值、关节范围和速率；任何违规命令拒绝发送。

S1版本标识为flashsac_revo3_die47_hist25_s1_v1；S0与S1加载时强制版本匹配。仍仅支持评估加载，不宣称完整物理状态resume。官方FlashSAC源码与引擎保持不变，沿用1-step/eager FP32配置。
