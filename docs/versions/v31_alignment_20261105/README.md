### 18.3 单位和数据链路的核对结果

- 当前真实环境、WM和Critic的关节顺序一致：little→ring→middle→index→thumb，拇指MCP/PIP/DIP/CMP/CMR。
- Actor、WM目标输入与真实执行均为绝对编码器位置；真实施加前只加已识别编码器偏置，
  quaternion统一XYZW、旋转增量左乘、误差旋转和6D列顺序一致。
- Actor与WM/Critic关节速度预缩放0.1，物理归一化std下限统一90°/s；物体速度×2只在网络输入仿射层，
  不改变仿真m/s、奖励或代价阈值。但RunningNorm有ε，因此×2并非数学上完全抵消：
  相当于物体线速度ε=0.005 m/s。停止的第400轮数据中三轴真实std约0.05234/0.01762/0.01247 m/s，
  ε贡献约0.90%/7.45%/13.85%的总方差；本次未盲目改变缩放。此数值来自受影响出生分布，不能外推为v31。
- 真实transition保存reset前物理状态；失败与timeout分开，8步真实TD在首个done截断，
  timeout使用reset前下一状态bootstrap。Critic均匀采样，WM优先采样带重要性权重。
- 真实探索与想象探索均使用tanh后同一AR(1)函数，Replay保留前一步角度噪声状态；视频关闭动作探索。
- 仍有结构性限制：Critic未条件化完整Actor观测历史/感知噪声/探索记忆，8步行为回报不是严格离策略校正；
  五头共同失败代价与bootstrap主导是算法设计问题，不属于已修复的坐标错误。
  WM有限差分动作响应与尾值梯度可信度还需在v31新数据上独立验证。
