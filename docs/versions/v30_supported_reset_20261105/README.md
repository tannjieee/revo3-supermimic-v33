# 直接接触手部的重置验证


## 17. 探索噪声位置与直接接触手部的出生状态（2026-11-05）

### 17.1 噪声在 tanh 后

当前训练采集顺序为 `logits → tanh → 加角度探索噪声 → 边界反射 → URDF 全范围仿射解码`。
令关节半范围为 h，采集动作为 `reflect(tanh(logits) + ε_rad / h)`。
ε 是以物理角度定义的 AR(1) 过程，稳态标准差0.5°、相关时间0.2秒；25 Hz时相关系数约0.819。
靠近边界的噪声经反射后分布会改变，不能把输出动作的所有位置都解释成严格0.5°标准差。
没有在加噪后再套一遍tanh，也没有对关节目标做增量积分或限速滤波。
logits超幅正则作用在tanh前，是另外一项训练损失，不是探索噪声。
确定性评估/周期视频关闭动作探索；感知噪声和物理随机化仍保留。

### 17.2 出生高度由当前手形决定

此前物体在固定名义位置附近采样，世界z另加±1 cm随机偏移；50 mm骰子会先悬空再落到手中。
新建manual-convex训练默认使用 `reset_joints_with_supported_object`：

1. 官方对象重置保留横向±2 cm、三轴朝向随机化；独立z偏移改为0。
2. 官方关节重置仍保留HOME附近±0.03 rad随机化。
3. 用实际关节状态、手基座姿态、当前物体凸包和重力方向计算支撑位置。
   若名义位置处于无穿透的手内空隙，就从该处向下查询；否则从上方无穿透位置查询。
   保留横向位置和朝向，只沿重力方向平移到第一次凸包接触，预留约2 μm数值间隙。
4. 同一reset事件覆盖初次出生、掉落重置、超时重置；在观测生成前写入位置。
   无隐藏仿真步、无预先落下或动态settling、无固定物体或辅助支撑力。

只读MuJoCo距离查询模型使用Newton实际资产重建；首次运行核对求解器中144个手部凸包和物体凸包。
只读查询启用native CCD；未修改Newton物理求解器参数。无支撑/无法收敛直接报错，避免默默回退成悬空状态。
质量100 g及0.8–1.2倍随机化、摩擦、动作协议、奖励和终止阈值不变。
新函数名称随env.yaml保存；旧检查点恢复仍遵循旧环境的自由落下初始化，不能静默混用新reset分布。
