# v28：WM 任务监督、终止学习与概率校准

2026-11-05。以 Git 标签 `algorithm-v27-orientation-costs-20261105` 为基线，
增加奖励、干净观测、终止和代价监督，保留当前手中 25 Hz 的物理和策略协议。
新代码位于分支 `codex/wm-task-supervision-v28`。这是模型学习路径修改，
不是对之前真实关节机械越界问题的修复；此前正式训练在第 1656 轮后退出。

## 与原文的关系

[SuperMimic §3.2，式 1](https://arxiv.org/pdf/2610.28480) 列出状态、奖励、
无噪声观测和终止 BCE 四类误差，同时允许解析头，并说明解析头不带单独损失。
因此不能说“只用状态损失就一定违反原文”。本工程有精确可微的奖励、观测和
代价公式；v28 保留这些解析函数，将其在预测状态上的误差作为额外任务一致性监督。
这是按本任务需求增加的辅助损失，并非声称逐项复现论文的具体实现。

终止概率采用可学习头，符合原文真实硬标签、想象软存活的区分。代价监督是
本工程 constrained BPTT 的扩展，论文式 1 没有本任务的五项代价。

## 模型输出与输入

动力学网络仍是 `164 → [2048,2048,2048] → 54`，输出 40 ms 内的物理增量，
经原残差重建得到 55 维下一物理状态。Actor 的 81×10 输入、21 维动作和
六头 Critic 均不改变，真机关节顺序、物理缩放、重力、碰撞和控制频率不改变。

新增终止网络 `57 → [64,64] → 1 logit`，ELU 隐藏层，7937 个参数；
WM 总参数由 8,853,558 增为 8,861,495。57 维是预测下一状态的
`q(21), qd(21), p(3), rotation6d(6), v(3), omega(3)`。
它复用动力学输入前 57 维的物理 affine 和真实数据 RunningNorm；没有第二套
手中原点、单位或隐藏的观测噪声。当前掉落规则不依赖目标姿态，终止头不输入目标。

终止网络的最后一层权重初始为零、bias 对应 1% 概率，仅是初始化先验，
不是校准结果。训练会更新全部参数；BCE 使用 logits 以保持数值稳定。

## WM 目标

```text
L_WM = E_uniform_windows Σ_j mask_j [L_s + L_r + L_o + L_d + L_c]
```

当前四项新增权重均为 1，保存到 Config 中，可通过构造配置调整；不使用
不透明的动态损失权重。各项先转成下述无量纲误差，不能直接叠加米、弧度和奖励原值。

| 项 | 预测与监督 | 缩放/损失 |
|---|---|---|
| `L_s` | 自回归预测物理状态 vs reset 前真实物理状态 | 保留六物理组缩放和组平均 |
| `L_r` | 解析 `r(s_hat, next_hat, a)` vs 仿真实际 reward | `((r_hat-r)/r_max)^2`，当前 `r_max=0.4`/步 |
| `L_o` | 从预测/真实下一状态构建的干净 Actor 观测 | 两端使用 Actor 固定 affine，81 维平方误差取均值 |
| `L_d` | 下一预测状态的终止 logit vs 真实 `terminated` | `BCEWithLogits`，无正类加权 |
| `L_c` | 五项解析预测代价 vs 真实状态上的同定义代价 | 各项 `log1p` 后平方差，再对五项取均值 |

`L_o` 不调用噪声/延迟采样，不使用 noisy history，也不使用自动 reset 后的
下一回合观测。q 使用编码器限位归一化，qd×0.1，物体/目标位置采用
`(p-hand_center)×10`，旋转使用 6D；这与 Actor 的固定物理缩放一致。
这里不使用 Actor 随训练变化的 RunningNorm 统计作为损失分母。
上一动作和固定目标槽位由已知指令复制，这些槽位的预测误差自然为零。
若显式关闭物体位置观测，维度随既有协议变成 78。

五项代价是实际关节速度、目标变化速度、物体角速度、物体线速度、掉落；
使用真实前态、真实下一态和实际下发动作产生监督。`log1p` 只用于 WM 回归，
避免极大超速的平方代价支配整个 WM 更新；Actor/Critic 的原代价数值、
零预算和姿态连续权重均保持不变。目标变化速度大多由已知动作决定，
在非 reset 步可能精确相等，因此该项 WM 误差为零是正常的。

## 序列、采样和标签

仍使用 8 步自回归：只有起点使用真值，中间不把真实物理状态喂回预测。
真实奖励与 `terminated` 进入 Replay 的 WM 序列读取；真实干净观测和代价
从已保存的物理状态解析重建，不额外复制 81 维观测缓存。

- 掉落这一 transition 的 reset 前状态、奖励和终止标签参与监督。
- `done = terminated | truncated` 只决定后续序列的 mask。
- 20 秒采样超时的 `terminated=False`；它不会成为掉落正样本。
- reset 后的后续项被屏蔽，不把 reset 跳变拟合成动力学。
- 机械限位/碰撞容量等健康检查异常仍直接退出，不作为普通掉落标签插入 Replay。

自适应 Replay 保留重要性权重，对包括 BCE 在内的完整损失纠正优先采样。
若不使用自适应 Replay，v28 WM 采用均匀窗口，关闭没有概率校正的事件档案
混入；避免事件过采样把终止概率基准率抬高。没有使用 `pos_weight` 或人为
凑成 1:1 正负样本。策略起点采样不受这个改变影响。

`wm_loss` 为加权总目标除以窗口长度；新增 `wm_loss_reward`、
`wm_loss_observation`、`wm_loss_termination`、`wm_loss_cost` 和五个
`wm_loss_cost_*`。新增分项也应用序列重要性权重。原六物理组日志保留旧口径，
不乘重要性权重，不能简单把所有分项相加复算总值。

## 想象中的存活权重

```text
d_hat = sigmoid(termination_logit / T + b)
c_0 = 1
c_(t+1) = c_t × (1-d_hat_(t+1))
```

新训练采用上述学习概率，默认 `T=1,b=0`。原
`sigmoid((0.3-distance)/0.01)` 只作为审计对照和历史 v27 路径，
不再驱动 v28 Actor 或奖励值头的 λ-return。真实掉落仍是原硬规则。
五项代价的存活系数仍恒为 1，避免策略利用预测掉落抹去后续代价。
Actor 更新时冻结 WM/终止头参数，但保留经过终止头和动力学的输入梯度。

## 为什么还需要校准

BCE 提供概率监督，但有限数据、类别稀疏、WM 多步漂移和策略分布变化会使
实际概率失准。单步误差会经存活概率乘积影响整段回报，因此需要检验，
不能用“加了 BCE”替代验证。尤其要看真实掉落正样本，而非仅凭总体准确率。

StreamAudit 在复制冻结模型后收集未来真实轨迹，在 1/8/16/32 步报告：
样本数、正样本数、真实基准率、平均预测概率、NLL、Brier、10-bin ECE，
正/负类各自 Brier、0.5 阈值召回率和误报率。分别对照学习原始概率、
当前校准概率和旧解析 sigmoid。审计只读，不在在线训练中追逐每个小窗口修改温度。

校准流程基于 [概率后处理校准的研究](https://proceedings.mlr.press/v70/guo17a.html)，
本实现具体采用二参数 `sigmoid(logit/T+b)`，不把它称为纯单参数 temperature scaling。
校准只改变冻结模型的读出，不改变状态预测或终止网络权重。

```bash
bash /home/brainco/reorientation/training/run.sh train \
  --num_envs 1024 \
  --resume /absolute/path/to/v28/model.pt \
  --env_config /absolute/path/to/v28/env.yaml \
  --calibrate_termination --eval_steps 1200 \
  --output_dir /absolute/path/to/new_calibration_output
```

该命令收集新的真实数据，冻结所有网络、优化器和归一化统计；不做正式训练。
按环境 ID 划分：mod 4 为 0/1 的环境用于拟合，2 用于选择，3 为独立报告测试。
同一环境的所有窗口/步长都留在同一组，避免相邻步跨分组泄漏。
只用拟合集优化 NLL，`T∈[0.25,4]`、`b∈[-5,5]`；拟合与选择各至少需要
20 个正样本和 20 个负样本。只有选择集 NLL 改善且 Brier 不恶化才接受。
独立测试组不参与拟合或接受决定，另外逐预测步长报告；没有正负两类时明确标记。

输出 `termination_calibration.json` 和含 logits/真实标签/环境 ID/步长的
样本文件；仅接受候选时额外写 `calibrated.pt`。源 checkpoint 不被覆盖，
报告记录其 SHA256。样本不足则返回明确原因，不能把 identity 参数称为已校准。
任何后续 WM 更新都会清除旧 T/b，因其不再对应原冻结权重。
一个后处理标量无法保证分布外、长于训练窗口的预测或路径梯度准确性。
