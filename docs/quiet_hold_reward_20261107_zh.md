# 带容差的持续到达与静稳奖励

2026-11-07；奖励协议：`single_exp_arrival_quiet_hold_v2`。

新建 manual-convex 训练默认启用，适用于当前 v33。保留全过程到达奖励；姿态误差在 10°（π/18 rad）以内时，到达奖励保持最大值。接近目标后，每个控制步都奖励物体低角速度、低线速度，并额外惩罚关节速度和执行目标变化率。没有一次性领取后停止的奖励，也不需要成功事件锁存。

## 默认公式

记最短 SO(3) 姿态误差为 θ，`e = max(θ - π/18, 0)`，`g = exp(-(e / (π/12))²)`。

```text
到达奖励 = 10 × exp(-(e/(π/2))²)
物体静稳 = 10 × g × exp(-(||ω||/0.3)² - (||v||/0.02)²)
关节运动代价 = g × mean((qdot / (π/9))²)
命令变化代价 = g × mean(((target_t - target_previous) / dt / (π/9))²)
单步奖励 = dt × (到达奖励 + 物体静稳 - 关节运动代价 - 命令变化代价)
```

`ω` 单位 rad/s，`v` 单位 m/s；两个运动尺度均为 20°/s，权重均为 1。尺度是连续函数的归一化参数，不是额外的速度硬阈值。`mean` 对 21 个关节求平均。物体处于容差内且所有速度、目标变化为零时，25 Hz 下单步奖励为 0.8。

到达奖励只使用一个指数项，沿用90°宽度，在远处仍提供引导。`g` 随接近目标连续增强；在容差内为 1，离目标 90° 时约为 4.43×10⁻¹³。因此远处的额外静稳和少动项很弱。目标附近允许必要的小幅修正，不强制冻结关节。

v33 的 `target` 使用 **EMA 后、扣除本回合编码器零偏后的几何目标**；比较相邻两个实际执行目标，不惩罚绝对关节姿态，也不直接惩罚原始策略输出。真实 action term 在 reset 后重新初始化上一目标，部分环境 reset 不影响其他环境。想象奖励由状态中的 EMA/零偏重建同一目标。

上述公式对应当前默认 orientation-only 配置。显式开启位置跟踪时，保留原有位置奖励和静稳位置项。历史版本的全局关节正则也按原配置保留；当前 v33 中这些旧权重为零。已有的五个风险 cost heads 保留，新增少动代价直接进入任务 reward。

## 时间与兼容

- 新建训练的环境时间上限为 **10 s**，25 Hz 下为 **250 控制步**。
- 超时是采样截断，继续从 reset 前状态 bootstrap，不标记为掉落失败。
- 已有检查点和保存的环境继续使用原来的奖励及时间配置。新字段的关闭默认值不改变旧环境哈希；不允许在恢复旧训练时静默替换奖励或时长。
- 新配置会保存到 `env.yaml`、`config.json` 和检查点。`--no-quiet_hold` 可关闭本次奖励改动；`--episode_length_s 20` 可显式恢复新实验的20秒上限。
- 新奖励可能为负；当前 v33 的线性输出 Critic 支持负回报。旧版仅支持非负回报的 bounded target Critic 会在配置检查阶段拒绝该组合。
- 成功率的既有连续保持判据没有改动；容差是奖励定义，静稳奖励不会在成功后停止。
- 环境日志中的 `stable_pose_exp` 记录“物体静稳奖励减去两个近目标运动代价”的净值。
