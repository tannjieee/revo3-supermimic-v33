## 0. 本版具体修改

### 0.1 HOME 初始化仍是绝对位置输出

Actor 最后一层权重初始化为零，bias 初始化为 `atanh(normalize(HOME_geometry - encoder_bias))`。所以初始目标等于合法 HOME 的编码器角，与观测输入无关；之后正常学习所有层。初始化没有添加运行时 HOME 偏移、速度积分或目标变化裁剪。拇指 CMP 的 1° 偏置在初始化时也明确扣除。

### 0.2 物理角度探索与回放记忆

```text
rho = exp(-control_dt / 0.2) = exp(-0.2)
noise_t = rho * noise_(t-1) + radians(0.5) * sqrt(1-rho^2) * Normal(0,1)
a_deterministic = tanh(actor_logits)
a_perturbed = a_deterministic + noise_t / joint_half_range
a_applied = reflect_to_minus1_plus1(a_perturbed)
q_target = lower + (a_applied + 1)/2 * (upper-lower)
```

反射函数为 `1-abs(remainder(a_perturbed+1,4)-2)`，保持全部可用限位范围，避免 clamp 在边界产生概率点质量。0.5° 是反射前探索偏移的稳态标准差；0.2 秒是探索相关时间。固定内部指令时，单步噪声差的标准差约 0.301°，明显小于 60°/s 在 25 Hz 下的 2.4°/步。只对探索偏移作时间关联，Actor 本身可以在两步之间改变绝对目标；不存在隐藏的目标平滑或硬限速。

Replay 增加 `exploration_noise_rad[B,21]`，保存动作采样前的偏移状态。真实采集和 8 步想象调用同一个函数、同一角度尺度、同一反射映射；真实回合结束将偏移归零，失败的想象轨迹冻结偏移。保存的 action、last_action、WM 目标和代价全部对应实际下发命令。这个字段不加入 Actor/WM/Critic 输入维度；WM 已显式接收实际目标，Critic 仍按原物理/控制状态估值，需持续用真实回报检查其对随机策略的估值。

推理和确定性评估不用探索。检查点恢复仍重建物理环境和 Replay，探索偏移也从零开始，和原有“非逐位续接”的恢复语义一致。

### 0.3 有效代价权重与防饱和

- 保留 v29 有界风险、六头真实 TD、目标 Critic EMA=0.02 和终止语义。
- 新训练 `cost_penalty=0.05`，从原来的 1 降低；这是明确的优化权重调整，不改变真实速度阈值、原始违规统计或 WM 的代价监督。
- 添加 `0.05 * mean(ReLU(abs(logits)-2)^2)`。仅对真实起点的过大 logits 提供直接纠正梯度；处于 [-2,2] 的 logits 不受该项影响。它不硬裁剪 logits，不改变 URDF 范围，也不把每个动作都拉向关节中点。
- Actor 学习率乘 0.25；保留 500 轮 WM/Critic 预热与 1000 轮 Actor 渐增。
- 每 50 轮在首个 Actor microbatch 分别计算奖励、加权代价、正则的梯度范数，记录代价/奖励梯度比与余弦；不额外执行优化器更新，不自动改变系数。这是原始参数梯度诊断，不等于 Adam 后实际位移。同一周期还固定最多 256 条真实历史，比较 Adam 更新前后的绝对目标角 RMS/最大变化量；不混入新物理步、探索或统计更新，不施加动作裁剪。

0.05 是依据 v29 梯度诊断选择的初始可调权重，不是已证明最优的约束乘子，也不是完整 NP3O。任何进一步调整都要同时检查掉落、姿态进展和速度超限。

### 0.4 真实多步回报与统一速度归一化

新训练使用 `critic_td_steps=8`（25 Hz 下最多 0.32 秒）。真实序列均匀采样，不用 WM 预测误差优先级，也不混入事件档案；第一次 done 后的数据全部排除。真实失败支付一次吸收态风险并截断，超时从重置前下一状态 bootstrap。详细公式和离策略局限见第 7 节。

单步原型的独立回放发现，Actor 归一化输入绝对值 P99 约 26.1，放大最严重的 20 个特征都是关节速度。预热期间手接近静止，累计速度方差较小；策略开始运动后，部分速度输入被放大至 P99 约 52。这是具体的分布变化证据，不代表已经证明它是全部掉落的唯一原因。

为避免低方差造成额外放大，Actor / WM / 在线及目标 Critic 的速度通道统一采用：

```text
scaled_qdot = qdot_rad_s * joint_velocity_scale
std_qdot = max(sqrt(running_variance + eps^2),
               joint_velocity_scale * input_joint_velocity_std_floor_rad_s)
z_qdot = (scaled_qdot - running_mean) / std_qdot
```

新训练 `input_joint_velocity_std_floor_rad_s` 默认取关节速度代价阈值 90°/s，即 π/2 rad/s；输入 scale=0.1 时下限为 0.15708。它是归一化的尺度下限，不是实际速度限制，也不裁剪观测或其梯度。真实方差足够大时仍采用真实统计。位置、姿态、关节角和 WM 的输出增量统计不变。

该下限作为 `std_floor` buffer 随各网络保存，推理和导出复用同一实现。历史配置缺失时取 0，历史 state_dict 不会凭空多出 buffer；历史 Critic TD 窗口缺失时取 1。两项设置及探索/正则配置均严格检查，不能通过 resume 静默更换。协议名区分单步原型、8 步回报和物理速度尺度版本。

## 2. 25 Hz、PD 与仿真频率

| 层级 | 周期 | 频率 | 对齐关系 |
|---|---:|---:|---|
| Actor 控制 | 40 ms | 25 Hz | 每次命令持续 8 个 PD tick |
| 执行器 PD | 5 ms | 200 Hz | 保留辨识模型采样周期 |
| 当前默认仿真积分 | 2.5 ms | 400 Hz | 每个 PD tick 有 2 个 solver 子步 |
| 等效执行器迟延 | 15 ms | — | 3 个 PD tick，短于 40 ms |

官方 NewtonManager 的执行顺序是每个 decimation 循环先更新 actuator，再执行 solver 子步。把 decimation 从 10 改为 8 不会把 PD 频率改成 25 Hz，也不会在每个 2.5 ms 子步重新运行 PD。

本次实时验证读取到 `policy_dt=.04, pd_dt=.005, decimation=8, solver_dt=.0025`。若使用显式绑定的 4 子步数值实验，则积分为 1.25 ms / 800 Hz，PD 仍为 200 Hz。这里没有修改 solver 或辨识参数去迁就控制频率。

本轮运行使用 `newton_mjwarp`，solver iterations=100、子步数=2、`nconmax=640`、`njmax=1024`。重力保持开启，世界重力为 `(0,0,-9.81) m/s²`；手和物体的 `disable_gravity` 均为 false。solver iterations 是每次积分内部的求解迭代预算，不是新的控制频率，也不能把 `400×100` 当成物理采样频率。

时域变化明确如下：

- 20 s 回合对应 500 个策略步；是采样截断，不是学习状态中的倒计时。
- 10 帧历史首末相隔 0.36 s；8 步 WM 监督与 8 步想象各覆盖 0.32 s。
- 至少保持 0.5 s 的成功条件取 13 步，实际判定持续时间为 0.52 s；不能四舍五入成 12 步的 0.48 s。
- γ 仍为 0.99/策略步，未暗中重新调参。因此其近似折扣尺度从旧 20 Hz 下的 5 s 变为 25 Hz 下的 4 s。这与模型显式预测长度是不同概念。

## 3. 手中坐标系与掉落

取手基座坐标系下 `origin=(0.055,-0.010,0.100) m`，它是v30确定后保留的网络位置原点，
对应当时的名义方块中心。第20节固定掌内初态改变了出生中心，**没有移动这个网络原点**。
该原点也不是部署时应直接填入的默认目标位置；实际目标位置见检查点metadata及第21节。

```text
p_hand_center = p_hand_base − origin
R_hand_center = R_hand_base
v_hand_center = v_hand_base
omega_hand_center = omega_hand_base
```

只平移原点，坐标轴与基座相同；姿态、线速度、角速度和位移增量不需额外旋转。Actor、WM、Critic 的物体位置和目标位置都使用相同原点，原点处网络位置特征为 0。

网络前的实际变换是 `(p_base−origin)×10`，即 10 cm 对应 1。居中消除固定偏移，×10 处理米制数值大小，两者并不互相替代。

仿真、Replay 和外部推理 API 仍保留 SI 基座坐标，在进入网络时统一转换；这避免把引擎状态、传感器噪声、目标命令或旧模型的数据误读成另一坐标系。导出的 Actor 保存相同 offset/scale，部署不能再自行多减一次原点。

真实掉落标签基于手中距离。v30 在工作空间内使用学习概率；预测位置已经越过真实掉落边界时，继续概率直接为零：

```text
d = ||p_base−origin||
real_drop = d > 0.3 m
v30_imagined_continuation = where(d > 0.3, 0, 1 − sigmoid(learned_logit / T + b))
v27_legacy_continuation = sigmoid((0.3−d)/0.01)
```

掉落统计和播放统计同步改用此定义。0.3 m 保持原来的距离阈值数量级，现在以手中原点为球心；它是脱离工作空间判定，不是触觉意义上的失去接触检测。

## 4. 网络结构与缩放一致性

| 模块 | 输入 | 隐藏层 | 输出 | 参数数 |
|---|---|---|---|---:|
| Actor | 810 | 1024→512→256 | 21 + tanh | 1,491,989 |
| WM（含终止头） | 动力学 164；终止头 57 | 动力学 2048→2048→2048；终止 64→64 | 54 个物理增量 + 终止 logit | 8,861,495 |
| 在线 Critic | 152 | 512→256→128 | 6 个有界价值输出 | 243,334 |
| 目标 Critic（冻结） | 152 | 512→256→128 | 同在线 Critic；EMA 参数 | 243,334 |

Actor/Critic 使用 ELU；WM 隐藏层使用 LayerNorm+SiLU。没有 CNN/RNN。Critic 共享 `[512,256,128]` 主干，末层依次输出奖励值、关节速度代价值、目标变化速度代价值、物体角速度代价值、物体线速度代价值、掉落代价值；六个输出先经 sigmoid，再分别乘固定回报上界 `[40,100,100,100,100,100]`（当前 γ=0.99、每步奖励上界 0.4）。训练使用 logits 的软标签 BCE，避免输出饱和时监督梯度消失。旧检查点缺少 `object_hold_costs_enabled` 时仍采用原三头，不把旧末层权重当作新六头权重加载。

### 4.1 同一物理量采用同一尺度

| 变量 | 所有相关网络采用的变换 |
|---|---|
| 编码器位置 | `2(q_encoder−lo)/(hi−lo)−1` |
| 真实几何 q | 先减 encoder bias，再用同一上下限变换 |
| 绝对编码器目标 | 同一限位归一化 |
| 关节速度 | ×0.1 |
| 物体位置、目标位置 | `(p_base−origin)×10` |
| 旋转 6D、上次归一化动作 | 保持自然尺度 |
| 物体线速度 | ×2 |
| 物体角速度 | ×0.1 |
| 域上下文 | 逐维除以真实环境平均绝对值，下限 1e-12 |

固定物理缩放后再进入 RunningNorm。Actor 看含噪/可能采样保持的观测，WM/Critic 看真实状态，因此三类统计量独立估计；目标 Critic 与在线 Critic 同步真实数据统计，不强制共用同一均值方差；**独立统计不意味着物理尺度不同**。

位置 affine 的定义来自同一个 `input_affine`；Actor 前向、真实统计更新、导出和推理复用它。新增测试用同一干净物理状态比对 Actor/WM/Critic 的共同输入，验证 q、qd、位置等缩放一致。

### 4.4 固定缩放、RunningNorm 与 WM 输出归一化

网络输入的完整处理为 `z=(x×scale+offset−running_mean)/sqrt(running_variance+eps²)`；context 先除以启动时计算的逐维平均绝对值。输入 RunningNorm 的 `eps=0.01`，统计从真实仿真采样累计，在计数达到 2e8 后停止更新。想象状态不更新这些统计。v30 的关节速度分母另外采用第 0.4 节的统一物理尺度下限；其余通道仍为上述公式。

Actor 对每一帧使用同一组 81 维统计，归一化后才展平成 810 维；没有为十个历史槽分别维护十组统计。编码器归一化和 qd 缩放发生在观测构造阶段，Actor 的 affine 只补充位置处理，不能在部署端把 q、qd 再缩放一次。

WM 的输出 `delta_norm` 是另一组 54 维真实增量统计，`eps=0.0001`；反变换为 `delta=network_output×delta_std+delta_mean`。输出是状态变化量，输入是状态/目标/context，两者不能共用统计。Actor 输出和 Critic 值输出不经过此反归一化。

## 5. 再次核对：WM 究竟需要预测什么？

它预测 **当前命令经过 40 ms 后、reset 之前的完整物理状态**。当前采用 54 维增量参数化：

| 输出切片 | 内容 | 重建后的意义 |
|---|---|---|
| 0:21 | Δq，rad | 下一时刻 21 个几何关节角 |
| 21:42 | Δqd，rad/s | 下一时刻实际关节速度 |
| 42:45 | Δp，m | 下一时刻物体中心位置 |
| 45:48 | 旋转向量增量，rad | 下一时刻物体四元数 |
| 48:51 | Δv，m/s | 下一时刻物体线速度 |
| 51:54 | Δω，rad/s | 下一时刻物体角速度 |

输出由 delta_norm 反归一化；平移/关节量相加，姿态用 `Exp(Δr)⊗q`。重建出的物理核心为 55 维。Δ 已是 40 ms 的变化量，不再乘 dt。原点平移不改变 Δp，所以无需新增平移输出维度。

q 和 qd 都需要：下一步 PD 响应依赖关节位置/速度，关节观测和速度代价也需要它们。物体 p/姿态/v/ω 都需要：任务奖励、保持、掉落及下一步动力学依赖这些状态。不能只预测物体姿态而丢掉运动速度。

不需要学习预测的量包括：目标位置/姿态（指令保持）、上次动作（已知赋值）、传感器噪声/延迟状态（按观测过程更新）、域参数（启动后固定）、奖励和五项代价（解析计算）。掉落概率改由学习头预测。本版本不预测触觉、接触力、扭矩或加速度，也不能据此宣称已具备准确的力矩约束。

物理状态/Replay 内部仍为 84 维：55 维物理核心、21 维上次动作、3 维目标位置、4 维目标姿态、1 维 reset 审计标志。最后一维不进入 WM/Critic，但成本在 reset 首步需要区分“没有上一策略目标”，以当前测量编码器位置作为第一步目标变化的参考。

15 ms 等效迟延短于 40 ms，所以一个上次命令覆盖当前步初始的迟延区段；steady-state 不需要多周期命令队列输入。reset 首步没有显式 flag 输入是有损简化，仍应单独评估首步预测误差。

SuperMimic 使用可微世界模型与短想象轨迹上的 BPTT 联合训练策略。本工程选择 54 维增量和上述残差重建；这一具体张量协议应以本地实现为准，不能称为论文要求。[原文](https://arxiv.org/abs/2610.28480)

### 5.1 “积分”在代码中的准确含义

这里的 `integrate_physical` 是一步残差重建，不是网络先预测加速度再用欧拉积分更新速度/位置。网络分别预测 Δq、Δqd、Δp、Δv；没有强制 `Δq=qd×dt` 或 `Δp=v×dt`。这种表示把接触、PD、阻尼和迟延在整个 40 ms 内的效果一起拟合，是否准确由真实轨迹监督和开环审计判断。

54 维内部输出与 55 维物理核心相差一维，是因为姿态增量使用三维旋转向量，而重建姿态使用四元数；不是漏掉了一个物理变量。

| 84 维 Replay 状态切片 | 内容 |
|---|---|
| 0:21 / 21:42 | 几何关节角 / 实际关节速度 |
| 42:45 / 45:49 | 基座系物体位置 / XYZW 四元数 |
| 49:52 / 52:55 | 物体线速度 / 角速度 |
| 55:76 | 上次施加的归一化动作 |
| 76:79 / 79:83 | 基座系目标位置 / 目标 XYZW 四元数 |
| 83:84 | 内部执行器队列是否已有上一命令的标志 |

状态、观测历史和传感器缓存是不同对象：84 维状态没有装入全部 10 帧历史，也没有装入位姿保持、噪声偏置等传感器缓存；Replay 另外保存它们，供想象路径复现同一观测过程。

### 5.2 物理状态监督损失

每次 WM 更新采样 2048 条、每条 8 步的真实序列。第一步使用真实起点，之后把预测状态继续送入 WM；使用记录的真实动作，不在中间用真实物理状态替换预测状态。遇到 episode 边界后屏蔽后续项，终止那一步的 reset 前状态仍可监督，避免把 reset 跳变拟合成动力学。

预测误差按 q、qd、p、旋转向量、v、ω 分六组。每组先按真实增量标准差和下表下限中的较大值缩放，再对组内平方误差取平均；最后对六组等权平均，避免 21 维关节量仅凭维数压过三维物体量。

| 误差组 | 缩放分母下限 |
|---|---:|
| 关节位置 | 0.003 rad |
| 关节速度 | 0.05 rad/s |
| 物体位置 | 0.003 m |
| 物体旋转残差 | 0.005 rad |
| 物体线速度 | 0.02 m/s |
| 物体角速度 | 0.05 rad/s |

当前自适应 Replay 对 WM 序列做优先采样，并使用重要性权重修正训练损失。反向传播的损失累加 8 步；日志 `wm_loss` 额外除以 8。六个 `wm_loss_*` 组指标不乘采样重要性权重，因此不能直接把它们平均后当成同一个 `wm_loss`。每轮执行 10 次 WM 更新，当前日志记录的是第 10 次更新的损失，不是十次均值。

### 5.3 新增任务损失与终止头

当前总损失为 `L_s + L_r + L_o + L_d + L_c`，逐步乘有效 mask 和采样重要性权重，
在 8 步上累加。`L_s` 保持上一节；新增各权重为 1，配置可追溯。

| 损失 | 定义 |
|---|---|
| L_r | 预测状态的解析奖励 vs 实际仿真 reward，除以每步上界 0.4 后平方 |
| L_o | 预测/真实下一物理状态构建干净观测，采用 Actor 固定物理 affine 后的均方差 |
| L_d | 57→64→64→1 终止头输出 logit，与真实 terminated 做 BCE |
| L_c | 五项解析预测/真实代价经 log1p 后的均方差；不修改 Actor 代价值 |

无噪声观测和真实代价均来自 reset 前物理真值，未对 noisy observation 学习。
20 秒 timeout 不是掉落正标签；掉落这一 transition 被保留，之后的序列被 mask。
新增目标将任务误差的梯度传给物理预测；奖励/观测/代价没有额外学习型网络。

想象存活采用 `1-sigmoid(logit/T+b)`；T=1、b=0 为未后处理的学习概率。
终止头与 WM 一起更新，Actor 更新时冻结其参数但保留输入梯度。
原人工距离 sigmoid 只留作 v27 路径及审计基线；v29/v30 的五项代价与奖励使用同一存活权重。

新增 TensorBoard 项为 `world_model/wm_loss_reward`、`wm_loss_observation`、
`wm_loss_termination`、`wm_loss_cost` 和五个 `wm_loss_cost_*`。
未来数据审计报告原始/校准/解析对照概率的 NLL、Brier、ECE、类别计数和召回率。
冻结模型后可独立拟合 T/b，用不同环境分组选择并测试；数据不足时拒绝校准。
继续拟合 WM 会清除旧校准参数。细节与用法见 [WM v28 说明](revo3_wm_v28.md)。

## 6. 代价、终止语义与 Actor 目标

### 6.1 保留原始物理违反

实际关节速度阈值为 90°/s，目标变化速度阈值为 60°/s；这些是训练阈值，
不是 100 rpm 的硬件声明上限。辨识文件的 2 rad/s 是激励轨迹的预设约束，
不能作为测得的硬件极限。

原始代价仍由 `violation_costs` 计算并写日志：

```text
c_speed = ReLU(max_j |qd_j| / (pi/2) - 1)^2
c_rate = ReLU(max_j |target_j - previous_j| / (dt*pi/3) - 1)^2
g = exp(-(orientation_error/(pi/12))^2)
c_omega = g * ReLU(norm(object_omega)/0.5 - 1)^2
c_linear = g * ReLU(norm(object_velocity)/0.05 - 1)^2
c_drop_distance = ReLU(distance_from_hand_center/0.3 - 1)^2
```

首次指令没有前一控制目标时，以当前编码器角作为目标变化速度的参照。
WM 的 L_c 继续使用这些原始代价的 log1p 一致性误差，帮助拟合物理预测。

### 6.2 有界风险与一次终止代价

为防止无上界的平方代价与自举共同放大，Actor/Critic 的训练代价改为：

```text
b_i = c_i/(1+c_i), i = speed, rate, omega, linear
b_drop = 0
p = real terminated label                  # 真实 Critic TD
p = 1 - imagined_continuation              # 可微 Actor rollout
C = 1/(1-gamma)                            # 当前为 100
risk_i = (1-p)*b_i + p*C                   # 所有五个代价头
continuation_i = 1-p                       # 奖励/代价一致
```

`c/(1+c)` 保留零违反区域和单调梯度，但压缩大违反的相对权重；这是明确的目标变化，
不是只调整日志缩放。阈值和原始超限统计不变。

**每个代价头都包含共同的掉落失败风险**，不再是纯粹的某一种速度代价。
掉落时一次支付 C，表示后续处在最坏约束状态的折扣成本；随后停止自举和预测状态推进。
这样没有把掉落后的未知物理轨迹当作训练依据，也不会因终止删除未来代价而奖励主动掉落。
单独的 drop 头学习折扣失败风险；距离越界原始代价仍保留为 WM 监督和诊断。

对任意 `b in [0,1]`、`V_next in [0,C]`：

```text
Q_i = (1-p)*b_i + p*C + gamma*(1-p)*V_next_i
0 <= Q_i <= C
∂Q_i/∂p = C - b_i - gamma*V_next_i >= 0
```

因此仅提高失败概率不能降低该头的代价。这里的共同失败处罚比 v28 更强，必须通过
真实姿态成功率、保持率和速度超限率评估是否过于保守，不能只看 loss 已经有界。

### 6.3 可微 Actor 的 8 步回报

`alive_0=1`，`alive_(t+1)=alive_t*(1-p_t)`；奖励、运行代价、终止代价、末端值
都使用同一存活权重。已知硬掉落样本冻结在最后一个有效状态，此后贡献为零。

```text
J_reward = sum_t gamma^t * alive_t * reward_t
           + gamma^H * alive_H * target_V_reward(s_H)
J_cost_i = sum_t gamma^t * alive_t * risk_(t,i)
           + gamma^H * alive_H * target_V_cost_i(s_H)
L_actor = -(1-gamma)*mean(J_reward)/reward_step_max
          + cost_penalty * sum_i (1-gamma)*mean(J_cost_i)
          + 0.05 * mean(ReLU(abs(real_start_logits)-2)^2)
```

当前 H=8、gamma=0.99、cost_penalty=0.05，每步奖励上界 0.4。
每项归一化代价回报仍位于 `[0,1]`；不含 logit 正则的 Actor 目标位于 `[-1,0.25]`（浮点误差除外）。
logit 正则非负、没有人为硬上界，故不能继续用 v29 的 `[-1,5]` 判断总 loss。分别监控任务目标、正则和梯度。
这些界来自目标和价值参数化，而非对最终 loss 做 clamp。
Actor 更新冻结 WM、在线/目标 Critic 的参数，但保留经过 WM 与目标 Critic 输入的梯度。
原始 Actor 梯度范数仍在裁剪前记录；实际全局范数上限为 1。

## 7. 真实 TD、目标 Critic、预热与检查点

在线 Critic 使用均匀抽取的真实序列训练，全部六个头都采用真实回报。新训练 K=8，历史和单步对照保留 K=1。
不把想象状态作为 Critic 的监督输入。先按首次 done 建立前缀 mask，包含结束转移，排除后续回合；设有效长度为 m≤K。每轮优化前固定标签：

```text
r_t = recorded_reward_t
c_t = (1-terminated_t)*running_risk_t + terminated_t/(1-gamma)
s_end_next = advance(recorded_s_(m-1), recorded_pre_reset_physical_(m-1),
                     recorded_action_(m-1), same_goal)
y_reward = sum(t=0..m-1, gamma^t * r_t)
           + gamma^m*(1-terminated_(m-1))*target_V_reward(s_end_next)
y_cost_i = sum(t=0..m-1, gamma^t * c_(t,i))
           + gamma^m*(1-terminated_(m-1))*target_V_cost_i(s_end_next)
unit_target = y / [reward_step_max/(1-gamma), C, C, C, C, C]
L_critic = sum_heads BCEWithLogits(logits, unit_target)
```

真实 `terminated` 决定失败；`done=True, terminated=False` 的 time limit 从 reset 前下一状态续算，不能越过 reset。
失败样本查询 Critic 时使用有效起点占位，随后续值乘零；不向它输入失败后或重置后的下一状态。
无效尾段在计算代价前先替换，避免无效数据的 NaN/Inf 经过乘零仍污染标签。标签不使用 WM 预测或学习终止概率。
六个头保留同一数学上界；超出上界报错，只容忍浮点尾差。记录有效窗口长度以及按有效转移计算的掉落/超时比例。

这项改动增加单轮可直接传播的真实回报跨度，不能保证提高姿态成功率。这里估计的是 Replay 行为策略的多步回报，未做重要性采样修正；旧数据与当前策略不一致时有离策略偏差。因此窗口先限制在 8 步，必须用独立确定性回放和真实多步标签继续评估，不将它宣称为严格的当前策略无偏估计。

Critic loss 使用固定回报尺度，不再按每批目标标准差缩放，另记录逐头归一化 TD MAE、
均值和最大估值。BCE 的软标签只是有界均值回归，不表示速度代价变成独立 Bernoulli 事件。

每轮 Critic 完成 5 epochs × 4 minibatches 后，目标参数执行一次
`target = 0.98*target + 0.02*online`；归一化 buffers 从同一真实统计直接同步。
目标网络不进入优化器，随检查点严格保存/恢复，也参与多进程一致性检查。

前 500 轮为 `wm_critic_warmup`：WM 和真实 TD Critic 更新，Actor 冻结。
之后每轮先拟合真实 Critic，再更新一次 Actor。Actor 学习率仍在 1000 轮内渐增，
v30 增加 actor_lr_scale=0.25，峰值约 5e-5；WM/Critic 基础学习率仍为 2e-4；
每轮 WM 更新 10 次。`lam` 为兼容旧配置保留，在 v29/v30 只参与返回的想象诊断目标，
不参与实际 Critic 拟合。旧 v28 的 λ-return 拟合路径完整保留给历史检查点。

新训练默认启用 `--stable_value_learning`。历史 v28 可以用原语义加载；
更换版本、gamma 或代价语义必须新开训练，不能静默继承 v28 的失真 Critic 和 Adam 状态。

## 8. 观测关节延迟是否必须？

**不必须。** 新训练将 `joint_delay_max_steps=0`，保留关节测量噪声与偏置。旧 v25/v26 检查点继续使用保存的原噪声配置。

应区分：

1. 辨识的总等效响应迟延约 12.984 ms，模型按 5 ms tick 量化为 15 ms；不能仅凭它推断单独的传感器读回延迟。
2. 额外观测迟延是训练人为加入的鲁棒性扰动。没有独立测量分布时，再叠加 0/40 ms 可能重复计入迟延，并且离散粒度过粗。
3. 若以后获得实测通信/编码器时间戳，应建立带时间戳的高频缓存，按毫秒分布读取历史状态。两帧线性插值可以作为近似分数延迟，但也引入平滑，不等同于真实异步采样；需要标明近似范围。

位姿传感器的更新周期、保持、抖动和噪声仍保留；本次仅取消额外的关节观测延迟，不是关闭所有传感器随机化。

当前 `noise_config` 的具体含义：

| 配置 | 当前值与作用 |
|---|---|
| `joint_noise_std` / `joint_bias_std` | 0.005 / 0.01；作用于归一化后的关节位置，不是 rad。前者是逐次高斯噪声，后者是 reset 时采样的高斯偏置 |
| `joint_delay_max_steps` | 0；关节位置/速度不附加整控制步延迟。当前关节速度没有单独的加性噪声项 |
| `max_period` | 位姿的位置/旋转各自采样 1–3 个控制步的更新周期，即 40/80/120 ms；中间保持旧观测 |
| `jitter_probability` | reset 时每个通道采样 0–0.1 的跳过更新概率 |
| `failure_probability` | reset 时每个通道采样 0–0.3 的异常测量概率，并非每个环境恒定 30% |

噪声界仅来自有限重复，不是统计置信保证。可解析样本选择偏向有接触响应的方向。

### 11.2 比较量与结论边界

对同一起点、同一物理角扰动 ε，比较正负动作分支末端姿态的相对旋转向量：

```text
r_real = Log(q_real_plus ⊗ conjugate(q_real_minus))
r_WM   = Log(q_WM_plus   ⊗ conjugate(q_WM_minus))
cosine_i = dot(r_real_i, r_WM_i) / (norm(r_real_i) * norm(r_WM_i))
relative_vector_error = norm(stack(r_WM - r_real)) / norm(stack(r_real))
```

同号分支重复两次，真实响应取两次差分向量平均。对称差分除以 `2ε` 可近似相应动作方向的有限差分导数；同一实验内比较方向余弦和相对误差时，该公共尺度抵消。不能把不同 ε、不同 seed 的绝对响应大小直接当作同一个 Jacobian 的幅值变化。

方向余弦接近 1 表示方向一致，接近 0 表示近乎正交，负值表示相反；这里报告的是合格样本的平均余弦。向量相对误差为聚合范数比，不是逐样本误差比的均值；大于 1 意味着按该指标，预测零响应的误差反而更小。它不代表每个样本都错误，也不单独决定策略更新效果。

该诊断为实际命令空间的有限扰动检验，没有计算完整 21 维动作 Jacobian，也没有证明 infinitesimal autograd 导数在所有接触状态都错误。现有证据足以否定“单步状态预测误差小，因此动作梯度可靠”的推断；下一步必须用未参与拟合的分支数据检验导数改善。

### 14.2 ×2 到底改变什么

物体线速度的 ×2 是 WM、Critic 及终止头共享物理特征的输入缩放，不是仿真速度翻倍。
Actor 不直接输入物体线/角速度；速度代价仍按 SI 单位和原阈值计算。

该通道没有额外 std_floor 时，RunningNorm 等价于：

```text
z = (c*v - c*mean_v) / sqrt(c*c*variance_v + eps*eps)
  = (v - mean_v) / sqrt(variance_v + (eps/c)^2)
```

因此固定倍数大部分被方差归一化抵消，真正保留的差别是有效 epsilon，及训练中的数值条件。
当前 c=2、eps=0.01，对应物理 epsilon=0.005 m/s。冻结模型三个轴的有效标准差为
`[0.09720, 0.03137, 0.02424] m/s`，有效输入增益为 `[10.29,31.88,41.25] /(m/s)`。
若将 c 改为 1、同步变换均值/方差但不补偿第一层，实际输入增益变为原来的
`[0.9961,0.9639,0.9417]`，不是简单减半；若仅改 scale 却沿用旧统计，则是错误的分布变换。

额外对第一层列权重作等价重参数化后，模型函数保持一致：WM 输出最大误差约 2.5e-7、
Critic 约 1.5e-5；输入梯度相对范数误差约 2.9e-7 / 1.3e-7，均为 FP32 量级。
这验证了“去掉 ×2 本身”不是修复动力学梯度的手段。该实验没有改写检查点。

仍需优化的是各物理量的有效标准差、分布漂移、损失缩放和可观测性。线速度 y/z 分母小于既有
0.05 m/s 保持阈值，值得做物理尺度下限对照，但阈值不是统计标准差的必然最优值。
不把这一现象当作新增下限已被验证的理由；输入下限、输出增量归一化与物理监督误差下限是三套不同量。

### 14.4 bootstrap：不宜仅凭范数直接删除

γ=0.99、H=8 时 γ^H=0.922745，尾值天然有很大权重；“范数大46–113倍”本身并不能证明尾值方向错误。
用前轮真实成对分支比较模型目标对动作的有限差分，尾值权重取0、0.1、1，其他项固定：

| 对照真实8步受约束回报差分 | 尾值0 | 尾值0.1 | 尾值1 |
|---|---:|---:|---:|
| seed44，12个合格响应，方向一致率 | 83.3% | 66.7% | 58.3% |
| seed45，15个合格响应，方向一致率 | 40.0% | 46.7% | 46.7% |

较小尾值并非稳定改善；而真实8步回报也不是无限时域目标真值。将真实分支末端同一个 Critic 加回标签后，
seed45 的方向一致率反而随尾值权重由0到1从27.8%升至72.2%，但那仍含同一个 Critic，不能当作独立证实其准确。
因此本轮没有把0或0.1设置成正式训练默认，也没有仅为降低梯度比例重复调小代价权重。

下一步应使用更长的冻结当前策略真实分支校验奖励/风险尾值，以及其对动作的方向；
同时把共同失败风险重复权重与运行风险分开实验。风险语义变化需要独立新版本和重训 Critic，不能静默沿用旧六头。
改良 WM 后再检验 Actor 的短程/尾值梯度与真实分支的一致性，才有依据逐步恢复联合更新。

## 15. 每 500 轮自动录制策略视频

2026-11-05 增加训练入口功能。新的 manual-convex 训练默认每完成 **500 轮完整更新**录制一次；
这里的“轮”是 `trainer.iteration`，不是物理步数、回合数或每个优化器内部 step。
因此触发点为 500、1000、1500……；续训继续按检查点中的绝对轮数计算。
第 500 轮仍处于 WM/Critic 预热边界，视频如实展示尚未更新的 HOME Actor。

| 参数 | 默认值 | 含义 |
|---|---:|---|
| `--video_interval` | 500 | 每 N 轮录制；0 显式关闭 |
| `--video_steps` | 500 | 500 个控制步/视频帧；25 Hz 下 20 秒 |
| `--video_seed` | 43 | 独立录制进程的固定评估 seed |
| `--video_timeout_s` | 240 | 录制超时上限；低于分布式 collective 的 300 秒超时 |

每次先原子保存不可变的 `model_N.pt`，即使 N 不是普通 `save_interval` 的倍数，也会保存。
随后 rank 0 启动独立 Newton GL 进程，载入同一检查点与该运行保存的 `env.yaml`。
训练在完整更新边界等待录制结束，其他 rank 同步等待；不会把播放转移加入 Replay，
不会调用 Actor/WM/Critic 优化器，也不会更新训练进程的归一化统计。
子进程继承固定版本运行环境和 GPU 可见性，移除 torchrun rank/elastic 标识。

视频为单环境、固定视角、1280×960、H.264、原速连续播放。Actor 不加探索噪声，
感知噪声、域随机化、重置、掉落、成功和超时仍保留。未添加动作速率限制或输出滤波。
同一 seed 有助于统一评估设置，但不能保证跨进程的物理轨迹逐位相同；单个视频也不能替代多环境指标。

### 17.1 噪声在 tanh 后

当前训练采集顺序为 `logits → tanh → 加角度探索噪声 → 边界反射 → URDF 全范围仿射解码`。
令关节半范围为 h，采集动作为 `reflect(tanh(logits) + ε_rad / h)`。
ε 是以物理角度定义的 AR(1) 过程，稳态标准差0.5°、相关时间0.2秒；25 Hz时相关系数约0.819。
靠近边界的噪声经反射后分布会改变，不能把输出动作的所有位置都解释成严格0.5°标准差。
没有在加噪后再套一遍tanh，也没有对关节目标做增量积分或限速滤波。
logits超幅正则作用在tanh前，是另外一项训练损失，不是探索噪声。
确定性评估/周期视频关闭动作探索；感知噪声和物理随机化仍保留。

### 19.1 饱和日志原来测错了量

当前探索位于tanh后，但`action_tanh_slope_sum`和流式审计原先用执行动作计算`1-action²`。

|---|---:|---:|---:|
| 4 | 0.00134087 | 0.0198956 | 14.84 |
| 6 | 0.0000245571 | 0.0198634 | 808.87 |

### 20.1 现在具体固定什么

新建50 mm／100 g的manual-convex训练使用`fixed_palm_v1`：

| 项目 | reset后的状态 |
|---|---|
| 手关节位置 | 原有合法托举HOME，完全对应Actor的几何HOME；下发编码器目标仍扣除已识别偏置 |
| 手关节速度 | 全部精确为0 |
