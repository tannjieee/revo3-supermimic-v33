# 58 mm 骰子质心椭球终止边界

用户确认将交互图中选定的椭球替换原 30 cm 终止球，越界直接重置。
固定参数见 `configs/supermimic_v33/position_boundary.yaml`，单位为米：

- 手基座坐标系中心：`(0.0337, 0.009358916334299222, 0.10065586490765209)`。
- 沿手基座 XYZ 的半轴：`(0.1061, 0.112, 0.1521)`。
- 对象：58 mm 骰子的物理质心，不是骰子根节点或任意顶点。

令物体根节点位置、姿态为 `p_root`、`R_object`，资产中的局部质心为 `c_local`。
所有量转到手基座坐标系后，使用：

```text
p_COM = p_root + R_object * c_local
rho² = Σ_j ((p_COM[j] - center[j]) / semi_axes[j])²
terminated = rho > 1
```

质心偏移来自实际 USD MassAPI，并与运行时几何核验；偏移随物体姿态旋转。
边界表面 `rho = 1` 不触发越界。真实环境在终止检查时标记失败并重置。
世界模型想象状态采用相同 COM 公式，越界 continuation 强制为 0；边界内保留
原有学习型存活概率（或未启用终止预测头时的解析存活概率）。掉落代价和校准
使用同一个归一化边界距离。

为兼容已有代价/校准接口，`drop_distance` 在椭球模式返回
`drop_radius_m * rho`。此时 `drop_radius_m = 0.3` 仅为接口比例尺，
不再表示一个实际的 30 cm 球。训练中以米报告的手中心距离仍单独使用真实
根节点距离；录像在椭球模式显示无量纲 `rho`。
网络输入中心 `hand_center_base_m` 不随终止椭球中心改变。

## 生效范围和恢复

新建 `manual_convex`、`hardware_center25_v3`、`die58` 训练默认加载本配置。
可用 `--position_boundary_config` 显式指定同格式配置。
环境 YAML、策略 Config 和运行元数据均保存参数及配置 SHA256。
恢复/录像优先使用已保存参数并校验一致性，不重新覆盖为当前默认 YAML。
历史检查点缺少这些新字段时保留旧球形边界。其他骰子规格不会自动应用此配置。

实际凸几何核验、CUDA Graph 边界反向传播、保存环境重新构建均通过。

诊断入口及证据位于工作区 `training/diagnostics/position_boundary_activation_20261107/`
下的 `check.py`、`newton.log`、`validation.json`、`validation.env.yaml`。
